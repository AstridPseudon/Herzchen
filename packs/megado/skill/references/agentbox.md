# Optional external/cloud handoff

This profile requires no cloud service to execute an ordinary local plan. Configure cloud delivery only for a concrete authorised environment and use its actual installed integration. Preserve source/candidate/skill identities, narrow credentials, permitted network/storage and provider limits, actual operation/session identity, task/evidence continuation and a recovery path. A handoff is not a new review allowance or deployment grant. If the intended platform is unavailable, name that dependency; do not invent launch commands or redirect to another account.

The original pinned skill has a provider-specific AgentBox reference. This neutral resource retains the boundary rather than installing that provider for every consumer. Validate any provider-specific setup against the exact receiving source and mandate before use.
